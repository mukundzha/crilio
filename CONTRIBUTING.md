## Contributing to Crilio
First off, thanks for taking the time to contribute! 🦾

Crilio is a solo, open-source project, and community input is what keeps it alive.

## 🐛 Found a Bug?

Do not open a PR right away.
Open a GitHub Issue with the bug label.
Include your OS, Python version, and the terminal output so I can reproduce it.

## 💡 Have a Feature Idea?
Open a GitHub Issue with the enhancement label.
Tell me what the use case is. I'm always looking for ideas that make Crilio more useful.

## 🛠 Want to Code?
If you want to tackle an existing issue:

Leave a comment on the issue saying you want to work on it (so we don't get two people doing the same thing).
Fork the repo and create a feature branch: git checkout -b feat/my-cool-feature.
Make sure your code passes crilio run --dry-run.
Open a Pull Request and reference the issue number (e.g., Closes #12).

## 🌱 Good First Issues
If you're looking for a place to start, look for issues tagged with good first issue. These are usually small bug fixes or documentation improvements.

Thanks for helping make AI apps safer! ⭐
